# Diagrammes UML pour la Gestion d'Atelier

Ce répertoire contient les diagrammes UML extraits du cahier des charges, convertis au format Mermaid.js pour une intégration facile dans votre dépôt GitHub.

## Liste des Diagrammes

| Fichier | Description |
| :--- | :--- |
| `use_case_diagram.mmd` | Diagramme de Cas d'Utilisation (Acteurs et Rôles) |
| `class_diagram.mmd` | Diagramme de Classes (Modèle de Données) |
| `sequence_diagram_1.mmd` | Scénario 1 : Soumission et validation d'une demande de tâche |
| `sequence_diagram_2.mmd` | Scénario 2 : Réception de livraison et mise à jour du stock |
| `sequence_diagram_3.mmd` | Scénario 3 : Création de devis et transformation en commande |
| `component_diagram.mmd` | Diagramme de Composants (Architecture Applicative) |
| `deployment_diagram.mmd` | Diagramme de Déploiement (Infrastructure Docker) |

## Comment les utiliser sur GitHub

Vous pouvez copier le contenu de chaque fichier `.mmd` et le coller directement dans vos fichiers Markdown (comme `README.md`) en utilisant le bloc de code suivant :

\```mermaid
[Contenu du fichier .mmd]
\```

GitHub rendra automatiquement ces diagrammes de manière visuelle.
